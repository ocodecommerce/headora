# Headora

Headless Magento 2 storefront(s) on Next.js.

- **Headora 2.0** (active) — vertical-agnostic App Router core, preset theming, multi-store, headless reviews, hybrid native-Magento checkout. Start here: [`README-2.0.md`](./README-2.0.md). Active branch: `headora2.0`.
- **Legacy v1** (frozen archive) — original Pages-router theme, preserved under [`legacy/`](./legacy/). See [`legacy/README.md`](./legacy/README.md).

```bash
cp sites/demo-fashion/.env.example sites/demo-fashion/.env
npm install
npm run doctor
npm run dev:fashion
```
