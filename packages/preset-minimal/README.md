# @headora/preset-minimal

The **minimal** look for Headora: colour and shape overrides on top of `@headora/preset-base`.

Installed automatically with [`@headora/core`](https://www.npmjs.com/package/@headora/core). Select it with `HEADORA_PRESET=minimal` in your storefront's `.env`; no code changes.

Start a store: `npx create-headora-app my-store`
